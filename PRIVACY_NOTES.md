# Stretheo Privacy Policy Notes

## Time Sensitive Notifications
Stretheo uses Time Sensitive notifications to deliver stress alerts that may require immediate attention. These notifications can break through Focus modes. No health data is included in notification content visible on the lock screen.

## HealthKit Data Usage  
Stretheo reads the following HealthKit data types on-device only:
- Heart Rate Variability (SDNN)
- Resting Heart Rate
- Heart Rate
- Respiratory Rate
- Wrist Temperature
- Sleep Analysis
- Physical Activity / Workouts

All processing is performed on-device. No HealthKit data is transmitted to any server. Data is optionally synced to the user's own private iCloud storage only.

## CloudKit Usage
User health and mood data is stored in CloudKit Private Database, accessible only to the user via their Apple ID. Editorial articles are stored in CloudKit Public Database and contain no user data.

## No Third-Party Analytics
Stretheo does not use any third-party analytics, advertising, or crash reporting SDKs.
